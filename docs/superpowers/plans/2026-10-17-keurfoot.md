# Keur Foot — plan de réalisation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Construire et publier sur GitHub Pages (non indexé) le site Keur Foot avec ses 20 premières pages, sur la base technique de Keurbook.

**Architecture:** Site Next.js 16 100 % statique (`output: "export"`), données écrites dans `src/lib/data/*.ts` et `content/conseils/*.md`, sans base. Publication GitHub Pages par GitHub Actions sous `/keurfoot` (variable `NEXT_PUBLIC_BASE_PATH`), avec un workflow Cloudflare Pages prêt mais manuel jusqu'à l'achat de keurfoot.com.

**Tech Stack:** Next.js 16.3.6, React 19, Tailwind 4, TypeScript 5, marked, lucide-react, tests `tsx --test` ; épingles : satori + @resvg/resvg-js + sharp + @fontsource/anton.

**Spec:** `docs/superpowers/specs/2026-10-17-keurfoot-design.md`

**Modèle :** `~/Dev/apps/Keurbook` (lecture seule). « Reprendre de Keurbook » = copier le fichier, remplacer Keurbook/livres/auteurs par Keur Foot/football, garder la logique et les commentaires en français.

## Global Constraints

- Branche `main` uniquement, pas de branche ni de PR ; un commit par tâche, puis `git push origin main`.
- Tout texte visible, commentaire et message de commit en français.
- Tag Amazon : `keurfoot-21` (valeur par défaut de `AMAZON_TAG`).
- Mention Amazon : « En tant que Partenaire Amazon, Keur Foot réalise un bénéfice sur les achats remplissant les conditions requises. »
- Pied de page : « Un site TOA KEUR » lié à `https://toakeur.com`.
- Contact : `keurfoot@toakeur.com` (même schéma que `keurbook@toakeur.com`).
- Phase GitHub Pages : `NEXT_PUBLIC_BASE_PATH=/keurfoot`, `NEXT_PUBLIC_SITE_URL=https://teiki5320.github.io/keurfoot`, `NEXT_PUBLIC_NOINDEX=1`, `NEXT_PUBLIC_ADSENSE_CLIENT=` (vide : aucun script Google).
- Aucun logo officiel, aucune photo de joueur, aucun visage dans les illustrations.
- Aucune donnée sans source : chaque fiche a un tableau `sources` (au moins 2 URL https, dont une hors Wikipédia pour les chiffres).
- Stats d'un joueur en activité datées par `statsAsOf` (AAAA-MM-JJ).
- Jamais d'ASIN ni de prix inventés : `asin: null` tant qu'il n'est pas vérifié à la main.
- Vérifications avant chaque commit : `npm run lint && npm run typecheck && npm test && npm run build`.
- Next 16 : lire le guide concerné dans `node_modules/next/dist/docs/` avant d'utiliser une API (voir AGENTS.md).

## Review Focus

1. Sous-dossier `/keurfoot` : une image, un lien du corps d'un conseil ou l'URL d'une épingle sans `withBase()` donne une 404 sur GitHub Pages → test dans la tâche 11 (aucun `src="/` ni `href="/` sans `/keurfoot` dans `out/**/*.html`).
2. Palmarès incohérent entre la page CAN, les fiches sélections et le Top 10 des pays titrés → test croisé dans les tâches 4, 5 et 7.
3. Indexation accidentelle de la version provisoire → test tâche 1 : `out/index.html` contient `noindex` quand `NEXT_PUBLIC_NOINDEX=1`.
4. Lien Amazon sans tag (perte de commission) → test tâche 3 : toutes les URL Amazon produites contiennent `tag=keurfoot-21`.
5. Stat d'un joueur en activité non datée, ou Top 10 avec 9 ou 11 entrées → tests tâches 6 et 7.
